A small question. An answer you can check.

01 / Generate

Same seed. Same task.

Arithmetic, strings, logic, machines, grids. Versioned generators produce a prompt and a reference answer. Public seeds make the question reproducible—not the model’s response.

02 / Attempt

Give the model the question.

One prompt, one response. Adapters see neither the answer nor the seed. Request and token budgets stay explicit; tools and agent scaffolding belong in separately labeled evaluations.

03 / Check

No vibes-based grading.

Exact, format-aware scoring. Signs, case, and grid boundaries matter. A separate final-answer diagnostic exposes formatting failures without quietly turning them into passes.

A programming puzzle is different from a reverse CAPTCHA.

Several projects challenge an agent to “prove you’re a bot” with time-pressured, natural-language, or secret-key tasks. They are useful gates, but they answer a different question. Clankdar is a capability ladder, not a gate that says “AI was here.”

Why a programming problem is the right shape.

It has a fact-of-the-matter answer that can be checked without a judge model. The prompt is public; the answer is not sent to the model. The same seed produces the same puzzle forever, so evidence is cumulative. The score is a percentage on a named cell, not a binary “you passed the gate.” And the contract is fully specified: one response, a token and time budget, and the suite version that generated the puzzle. That is what a capability benchmark needs.

We tested the models. Then we tested the test.

Three tracks, one source of truth.

The v2, frontier, and tool-agent calibrations are all public. Five requested model aliases, held-out seeds, full responses, hashes, error counts, confidence intervals, usage, and replayable reports. Every score is recomputed from the published data.

The thesis got sharper.

The suite separates unaided systems from 0% to 87.6% strict, and bounded tool-agent episodes from 19% to 81%. Pooled tiers are not one intelligence number, and the two tracks are not comparable. Clankdar publishes family/tier capability profiles instead of polishing a fake scalar ranking.

Benchmark first. Admission carefully.

Measure a floor. Don’t mint trust.

The long-term goal is scoped, one-use capability checks for agent networks. A valid response could inform a rate limit or an admission policy. It must never, by itself, grant tool access, authorize a payment, or make another message trustworthy.

Different questions need different proofs.

Hashcash meets a declared hash target. A witness satisfies a replayable program contract. A puzzle answer satisfies that puzzle. The stack is implemented reference code — sealed-seed attestation, admission sessions, subject-bound receipts, a signed transparency log over the issuance ledger, and a drift monitor that gates on score-band regression — documented separately from the shipped benchmark.

A cheeky name.
A narrow promise.

Clankdar is not a bot detector, a personhood test, or a certificate of general intelligence. This is an experimental benchmark and protocol research project—not a production admission service. Public puzzles can be memorized, solved with code, or outsourced. We report the conditions and keep authority somewhere else.
