How a check works

{{PORTFOLIO_HEADING:how-title}}

  1. {{PORTFOLIO_HEADING:issue-fresh-puzzles}}

    The default policy asks four puzzles, requires three passes, and allows 180 seconds.

  2. {{PORTFOLIO_HEADING:connect-your-agent}}

    You choose the model and provider that answers. Clankdar doesn’t call a model for you.

  3. {{PORTFOLIO_HEADING:score-each-answer}}

    A program computes the reference answers. Each reply is right or wrong, without a judge model.

  4. {{PORTFOLIO_HEADING:keep-the-signed-result}}

    The receipt records the answers, deadline, and policy as JSON. Anyone with the issuer’s public key can check its signature and rescore the answers.
