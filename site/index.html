Make your first signed receipt.

The demo runs a whole check on your machine. It creates four fresh puzzles, answers them with an included script, signs the result, verifies it, and saves the receipt as JSON.

You need Bun 1.3.14, but no API token or model account. Because a script supplies the answers, the score only shows that the flow works; it is not a model benchmark.

Connect your own solver →

git clone https://github.com/hraness/clankdar.git
cd clankdar
bun install --frozen-lockfile --ignore-scripts
bun run try

Check the receipt yourself.

A receipt records the submitted answers, their deadline, and the policy they were scored under: the puzzle types, how many must pass, and the time limit. With the issuer’s public key, you can check the signature and rescore the recorded answers. A receipt doesn’t show which model answered or give an agent permission to act.
