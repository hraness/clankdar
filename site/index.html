{{ALGAL_CHALLENGE}}

A program, an answer, a receipt.

Algal’s bounded expression language gives each puzzle an executable answer. Clankdar runs the shared evaluator, checks the response exactly, and records the conditions. No judge model.

The signed receipt includes what a verifier needs to reproduce the result. Each completed check is one JSON object in R2; your app owns identity, schedules, and acceptance.

How Clankdar uses Algal →

  1. Create a check

    POST /v1/checks
    Get fresh prompts and a deadline.

  2. Submit answers

    POST /v1/checks/:id/responses
    Your system supplies the solver.

  3. Keep the result

    GET /v1/checks/:id
    Retrieve the signed JSON receipt.

Other systems use puzzles too. Clankdar’s distinction is inspectable task evidence. Public tasks can be solved with code or delegated; results do not establish model identity or human presence.
