Method and downloadable evidence

Each model received the same 25 task settings and 20 seeds per setting: 500 attempts per model, 2,500 in total. Calls used Vercel AI Gateway with a requested temperature of 0 and a 4,096-token completion budget. The table shows the requested model aliases, not independently verified model identities.

The scorer compares each complete response with a deterministic reference answer. Provider errors are separate from wrong answers. The report retains counts, confidence intervals, and results for each task; formatting diagnostics are not counted as passes.

The recorded test is clankdar-suite-v2, with scorer clankdar-score-v2 and seeds 101–120. The manifest pins the suite hash and source revision and records an uncommitted source change at collection time. The site build rescores every retained response before publishing these scores.
